# 嵌入式学习站 · Embedded Learning Station

一个无构建步骤的 HTML / CSS / JavaScript 中文嵌入式学习网站，可直接通过 GitHub Pages 发布。前端无需构建；可使用 Supabase Auth 与 PostgreSQL 为个人学习数据提供跨设备云同步。

## 界面体验

界面采用暖白底色、深松绿导航与低饱和鼠尾草绿作为主色，使用克制的边框、柔和阴影和更清晰的留白建立层次。顶部导航提供轻量磨砂质感；卡片、按钮、搜索框与弹窗使用统一的缓动曲线和细微位移，避免过度弹跳或长时间装饰动画。移动端导航采用抽屉与背景遮罩，支持点击遮罩、选择页面或按 Escape 关闭，并锁定背景滚动；主要交互控件具有清晰的键盘焦点样式，弹窗支持焦点约束。首页芯片插画以低频、低幅度动效增加灵动感；同时支持系统“减少动态效果”偏好，并针对窄屏调整布局和字号。第二轮进一步统一了页面背景、顶栏、按钮、卡片、表单与弹窗的层级和触控尺寸，并提升常用说明文字的对比度、卡片边界辨识度和危险操作反馈；增加 `prefers-contrast: more` 高对比度偏好适配。

## 第二轮体验优化：视觉一致性与删除撤销

- **视觉层级**：统一页面背景、磨砂顶栏、按钮状态、卡片边框/阴影、表单和弹窗圆角；扩大关键标题与辅助文字的字号层级，减轻信息密集页面的阅读负担。
- **触控便捷性**：提高按钮和图标按钮的最小操作尺寸；移动端页面标题与主操作垂直排列，统计卡片保持双列，复杂表单在窄屏改为单列，卡片列表按屏幕宽度自适应。
- **删除后撤销**：删除单条记录、资源、知识卡片或课时后立即显示“撤销”操作；删除课程模块或阶段仍保留二次确认，因为它们会级联影响多节课。撤销窗口为 10 秒，提示条带有时间进度提示，支持点击撤销按钮或在非输入/编辑区域使用 `Ctrl+Z` / `⌘Z`。撤销会恢复删除前的完整工作区快照，包括学习完成状态、课程编辑和自定义内容。
- **撤销安全边界**：撤销快照保存在当前标签页的 `sessionStorage`，同一标签页刷新后仍可使用剩余的撤销时间；标签页/浏览器会话结束后不保留短时撤销记录。删除后若继续进行新的数据修改，旧撤销会自动失效，避免撤销时覆盖较新的编辑。云端恢复成功后也会清除本机旧撤销快照。

## 功能

- **学习总览**：汇总累计学习时长、课程学习完成度（按用户手动标记统计，不代表通过测验或客观掌握）、常用知识模块、最近知识卡片和学习记录。
- **学习地图**：现有 14 个知识模块、133 个内置知识单元（在原有 86 节基础上新增 47 节细分课程）。保留原有 C 语言、计算机底层、MCU 启动、GPIO/中断、定时器/PWM、UART/I²C/SPI、ADC/DMA、RTOS、工具链调试和固件可靠性内容，并补齐 GNU Make/Makefile、GCC 与交叉编译、Binutils、链接器与 map 文件、GDB、汇编与 ABI/EABI、MMU/MPU/Cache、Bootloader、硬件信号完整性、软件设计、模块管理、错误管理、单元测试、代码覆盖率、静态/动态分析和性能分析。
- **学习地图与可编辑课程**：已移除单独的“推荐学习顺序”板块，学习地图聚焦可检索的知识模块；内置 14 个知识模块、133 个知识单元；所有模块标题、分类、级别、预计时长和简介都可以编辑；每个课程阶段的标题与目标、每节课标题、简介、完整正文（含代码示例说明、逐段讲解、练习问题与答案）、要点、参考答案和原书关联都可以编辑并保存。编辑课时和新建课时的正文采用同一套富文本工具栏，支持插入常见位图、PDF/文本/CSV/Markdown/JSON/ZIP/Office 附件、图片尺寸调整及详情放大；模块、阶段和课时均可删除，模块/阶段删除会提示影响范围并同步清理子内容及完成状态。还可在现有模块中新增课时。旧课程 ID 保留，原有完成进度继续匹配。
- **学习内容详情**：课程卡片可点击进入课程；单元可打开完整正文；支持前后切换、手动标记完成、课程内导航和把练习带入每日记录。部分单元标注了原书对应章节，方便按书对照学习。
- **每日记录**：以月历和颜色块整理大量学习记录，支持原生日期选择器直接跳转到指定年、月、日；点击日期可查看当天的记录，点击日历色块可直接打开对应记录详情。新增记录改为弹窗表单，不再长期占据页面；详情支持编辑、删除，按类别筛选，并统计学习条数与投入时长。单条记录删除后可立即撤销。
- **资源收藏**：内置 Arm、CMSIS、STM32、GCC、Git、FreeRTOS、Zephyr 等参考入口；所有资源均支持详情查看、编辑名称/链接/分类/标签/说明，以及从详情或编辑窗口删除。单条删除支持撤销。
- **我的知识库富文本编辑**：新建和编辑界面均提供可视化格式工具栏，可设置字体、字号、正文/标题 1–4、引用、代码段、左/中/右/两端对齐、加粗、斜体、下划线和列表。支持在光标所在位置插入图片和附件；图片框可用鼠标或触屏拖动右下角手柄调整尺寸，阅读时点击图片可放大；支持 PDF、文本/CSV/Markdown、JSON、ZIP、Office 文档和常见位图作为下载附件；HTML、SVG 与脚本等主动内容不允许内嵌。保存、再次编辑、JSON 备份和已配置的跨设备云同步均保留富文本结构。保存前会按 HTML 白名单清理危险标签和属性。
- **偏好与数据**：自定义工作台称呼；支持导出 JSON、从备份恢复和重置。导出备份包含课程、阶段、课时、增删改记录与个人学习数据；导入和云端恢复会先校验工作区结构，无效文件不会覆盖当前数据。删除记录、资源、知识卡片、课时、阶段或模块后，提供 10 秒撤销窗口；撤销恢复完整工作区快照，包含完成状态和编辑内容。
- **跨模块搜索**：可搜索课程、课程正文、知识卡片、资源和学习记录；点击结果可直接打开课程/课时、查看对应记录详情，或跳转并高亮命中的笔记与资源。
- **本地优先与跨设备同步**：所有修改先保存至浏览器 `localStorage`；配置 Supabase 并登录后会自动上传版本化的个人工作区，通过 Realtime 与 20 秒轮询接收其他设备更新。断网时仍可继续本地编辑；版本冲突会暂停上传并提供“采用云端 / 采用本机”选择，避免静默覆盖。
- **简约视觉与流畅动效**：暖白与深松绿的低饱和配色、磨砂顶部栏、细腻卡片层次、统一缓动、轻量页面入场和弹窗过渡；减少动态效果的系统偏好会自动生效。

## 本轮工程优化（UX / 内容表达 / 安全与维护）

- **界面与可访问性**：移动端导航改为带遮罩的抽屉；支持遮罩关闭、导航后自动收起、Escape 关闭、焦点返回和背景滚动锁定。主导航具备 `aria-expanded` / `aria-controls` 状态，弹窗增加焦点进入与 Tab 焦点约束，主要控件统一 `:focus-visible` 反馈。第二轮统一页面视觉层级与窄屏触控布局，并提升关键说明文字字号。
- **可撤销删除**：常规单条删除不再弹出浏览器原生确认框，而是直接删除并显示 10 秒撤销按钮；课程/阶段等批量级联删除仍先确认。撤销支持点击按钮和 `Ctrl+Z` / `⌘Z`，恢复完整状态快照；期间发生后续数据写入时会使旧撤销失效，防止误覆盖新数据；编辑弹窗打开时会阻止撤销，避免覆盖未保存输入。
- **学习反馈准确性**：手动勾选只统计为“学习完成度”，不再将其描述为“掌握度”。课后答案默认收起，鼓励先独立作答，再展开参考分析。
- **富文本安全与完整性**：白名单新增表格结构及受限单元格属性；普通链接只接受 HTTP(S)，内嵌数据链接仅用于受控附件；SVG、HTML 与脚本等主动内容不作为可点击的 data URI 保存。图片与附件上传阶段会先检查 MIME 类型。
- **数据保护**：补齐原先缺失的 JSON 导出实现；导入与云端恢复复用工作区结构校验，结构不符合预期时不覆盖当前数据；动态 ID 和日期属性统一进行 HTML 转义。
- **可维护性**：样式和主交互脚本从 HTML 拆分到 `styles.css` 与 `app.js`，仍保持无需打包器/构建步骤的静态部署方式。可通过 `node scripts/validate-project.mjs` 执行静态项目检查。

## 本次学习地图扩充与结构调整

本版以用户提供的李云《专业嵌入式软件开发：全面走向高质高效编程》作为主题来源，按硬件、工具、编程语言、设计、操作系统和质量保证等方面组织知识地图。原书相关主题用于提供术语和方向；零基础前置概念、部分工程练习及平台适配说明属于为学习路径补充的教学内容，不表示原书一定以同名独立章节展开。

本次重点重构“底层原理和基础知识”，将原本少量大课拆成带明确先后顺序的学习阶段。三个核心基础模块现在分别包含 **22 节 C 语言与内存、18 节计算机底层与数字基础、10 节 MCU 启动与系统架构**，合计 50 个基础单元；其他外设、RTOS、工具链、设计与质量保证模块同样进行了拆分和补充：新增寄存器/栈帧/ABI、预处理与重定位、可重复构建、电气阈值/上拉/去耦、GPIO 消抖/EXTI、定时器计算/输入捕获、UART 缓冲/I²C 恢复/SPI 模式、ADC 采样时序/DMA 所有权、RTOS 优先级反转/超时/临界区、故障恢复/崩溃记录、模块契约/依赖图/资源回滚、测试替身/硬件在环/持续集成等单元。每个模块现在按学习阶段组织，并提供对应阶段目标。课程详情会按学习阶段分组，每阶段附有可检查的学习目标，不再只显示一长串平铺小节。

课程卡片按前置知识组织：**C 语言 → 计算机底层 → 汇编与 ABI/EABI → MCU 启动 → 构建调试 → 硬件接口 → 外设驱动 → RTOS → 可靠性、设计与质量保证**。这只是内容编排，不再单独占用学习地图顶部空间；有项目经验的学习者可以通过搜索直接打开相关课程。

C 语言课程按“程序结构和类型 → 表达式与控制流 → 对象作用域和复合类型 → 数组与指针 → 面向固件的限定符/共享数据 → 未定义行为、栈、堆与内存段”递进。计算机底层课程按“数制与数据表示 → CPU 寄存器和指令执行 → 地址空间与存储介质 → 总线与 MMIO → MPU/MMU、Cache 和故障现场”递进。MCU 启动课程按“复位与向量表 → .data/.bss 和运行库初始化 → 时钟配置 → 链接与映像 → 启动故障定位”递进。旧知识单元 ID 保持不变，已记录的完成状态仍可匹配；由于增加了学习单元，整体完成百分比会按新的总单元数重新计算。

### 用户可编辑与删除范围

学习地图不是只读目录。进入地图后可以编辑每个知识模块的标题、分类、级别、时长和简介，也可以在模块编辑窗口删除模块；进入模块后可新增课时、编辑或删除学习阶段与课时。编辑课时时，完整正文、示例代码、说明、步骤、常见问题、要点、练习与参考答案均汇入正文/字段编辑界面，保存后会覆盖原先生成的对应文字内容。删除阶段会同时删除该阶段所含课时，删除模块会移除其下课时与完成记录，操作前会显示影响范围并要求确认。保存后变更会同步反映在地图、课程详情、学习进度与相关搜索结果中。

“我的知识库”支持卡片放大查看；在大尺寸详情视图中可阅读全文，也可进入编辑模式调整标题、分类与正文。富文本编辑器支持字体、字号、标题等级、段落对齐、加粗/斜体/下划线、编号/项目列表、引用与代码段；保存会更新原卡片，格式在详情查看、备份导入导出和云同步中保留。资源收藏同样支持放大查看、编辑和删除；内置资源与用户添加的资源采用相同的交互。

### 当前教学呈现方式

课程统一按“先理解核心概念 → 阅读本节针对性代码/工程示例 → 按步骤追踪输入、状态与输出 → 看常见误区与排查 → 阅读直接问答 → 完成练习并核对参考答案”的顺序呈现。每一节都有明确的学习目标、具体示例、逐段说明；练习答案默认收起，先独立作答后再展开核对；问答不只提出问题，页面会同时给出解释或推导。对 C/CPU/链接/驱动/RTOS 的通用示例，会标明伪代码、工具链或芯片依赖，避免把说明性代码误当作可直接烧录的完整实现。

图解只放在空间关系、内存布局、位模式、总线事务、时序或状态交接等确实能通过视觉降低理解成本的小节，不再按“每小节必须有图”批量套模板。当前 30 张针对性图解分布在 27 节课程中，图型与课程内容对应，每张图都有专属的读图说明；其他小节优先用代码、手算、操作步骤和排查清单解释，不为凑数添加重复流程图。不同课程的代码示例、图标题和代码标题经过重复性审计。

除基础课程外，全部其余课程也已进一步拆小，补充了可以独立学习和验证的机制主题。全地图现为 14 个模块、133 个内置知识单元；原有的 86 个知识单元 ID 保持不变，新增 47 个主题单元。每课包含主题讲解、学习分析步骤、常见误区和自测/实践任务，避免只列概念名称。

为照顾初学者，每个内置知识单元均在原有正文基础上新增“从零开始建立直觉、一步一步学会分析、初学者常见误区与排查方法、自测：达到什么程度才算掌握”四个部分。内容强调先理解问题与底层机制，再画出执行/数据流程、预测结果、用工具验证，最后主动测试边界条件。示例以通用 C / MCU 工程场景说明。页面只做知识点归纳和通俗化重写，不复制原书大段文字；详细理论与书中示例应以原著为准。书中部分开发环境和工具版本较早，实际操作时请同时核对目标 MCU、编译器与 RTOS 的当前官方文档。


## 跨设备云同步（Supabase）

项目已经包含 Supabase 登录与同步集成。**需要你先创建自己的 Supabase 项目并执行一次数据库 SQL；当前交付包没有你的云端项目凭据，因此尚未连接到实际云端。**

### 1. 创建并配置 Supabase 项目

1. 在 [Supabase](https://supabase.com/) 创建一个项目，并记下数据库密码（仅你自己保管，不需要填进网站）。
2. 打开 Supabase Dashboard 的 **SQL Editor**，执行本项目的 `supabase/schema.sql`。它会建立 `embedded_learning_workspaces` 表、开启 RLS，并只允许已登录用户读写自己 `user_id` 对应的工作区；不会授予客户端删除表记录的权限。
3. 在项目的 Connect / API Keys 页面复制 Project URL 与 **publishable key（推荐）**。旧项目的 `anon` 公共 key 暂时仍可用，但 Supabase 已宣布将在 2026 年底前逐步弃用旧式 `anon` / `service_role` key，建议新项目直接用 `sb_publishable_...`。
4. 部署网站后进入「偏好与数据 → 跨设备云同步 → Supabase 连接配置」，填入 URL 和 key 并保存。若希望网站在每台设备打开时自动带有连接配置，可在部署前编辑 `sync-config.js` 中的 `url` 与 `publishableKey`。公开 publishable key 可存在浏览器代码中，但**绝不能把 `service_role` 或 `sb_secret_...` 密钥放在前端**。参考：[Supabase API keys 官方说明](https://supabase.com/docs/guides/getting-started/api-keys)。
5. 在 Supabase Authentication 设置中确认启用了 Email 登录，并将实际 GitHub Pages 站点地址加入允许的 Site URL / Redirect URLs。若开启邮箱确认，首次注册后需要点击验证邮件再登录。

### 2. 在网站里登录并迁移数据

1. 在「偏好与数据 → 跨设备云同步」创建账号或登录。
2. 如果云端还是空的，点击 **将此设备的数据迁移到云端**。这是显式操作，不会在你没确认时自动上传覆盖。
3. 在其他设备打开同一个 GitHub Pages 地址。如果你没有把默认连接信息写入 `sync-config.js`，先在「Supabase 连接配置」中再次填写相同的 Project URL 与 publishable key（该配置只保存在当前设备的浏览器里），然后使用同一个账号登录。如果账号已有云端工作区，选择 **从云端恢复到此设备**；这一操作会覆盖这台设备当前的本地工作区，建议事先导出 JSON 备份。
4. 登录并完成首次关联后，学习地图编辑、完成状态、知识卡片、资源收藏、每日记录与工作台偏好都会参与同步。

### 3. 数据同步与冲突安全

- 所有现有编辑仍先保存本机，然后在短暂防抖后上传；网络暂时不可用时保留本机数据并重试。单次云端写入串行执行；如果上传期间又有新编辑，会在当前上传完成后继续上传，避免旧快照清掉新变更。
- 通过数据库行 `revision` 做乐观并发检查。若其他设备先修改了云端，当前设备不会直接覆盖，而是在同步面板提供两个明确选项：采用云端版本（覆盖本机）或采用本机版本（覆盖云端）。选择前建议导出 JSON 备份。
- 登录另一个新设备时，若云端已存在数据，不会静默把该设备初始数据上传覆盖；需要明确选择恢复或覆盖。
- 账号退出不会清除当前浏览器缓存。存在未处理冲突时会阻止退出；同步中的新编辑会排队上传，未完成上传时会提示先等待同步。共享设备上退出账号后，本机缓存仍会保留，请只在个人设备上使用或在离开前清理浏览器数据。
- 支持通过 Supabase 邮件发起密码重置，并在返回网站后设置新密码。
- 当前版本把每个账号的可编辑数据存为一个版本化 JSON 工作区，适合个人学习站。若将来需要多用户协作、细粒度历史版本/合并或文件附件，再考虑将记录拆成多张数据库表。

## 编辑工具与撤销提示（2026-11-12）

## 富文本正文、图片与附件

“我的知识库”与“学习地图 → 编辑课时内容”的完整正文使用同一套富文本工具栏。工具栏采用类似 Word/Excel 的分组功能区，明确拆分“字体与段落样式、编辑历史、文字强调、颜色与高亮、段落排版、结构与链接、图片与附件”七组，按钮均有独立图标、操作名称和悬停提示；支持字体、字号、正文/标题等级、加粗/斜体/下划线/删除线、上标与下标、文字颜色与高亮、撤销/重做、段落对齐、缩进、项目符号与编号列表、超链接、表格、分隔线、引用和代码段；图片和附件可以插入在光标所在的任意正文位置。图片可以拖动右下角手柄调整宽高，改变后的尺寸会写回正文并随保存保留；查看详情时点击图片可放大。触屏设备也支持拖动手柄。支持 PDF、文本/CSV/Markdown、JSON、ZIP、Office 文档和常见位图作为附件；HTML、SVG 和脚本文件不允许以内嵌数据链接形式打开。

常见浏览器支持的图片格式可直接显示（例如 PNG、JPEG、GIF、WebP、AVIF 和 BMP）。如果浏览器无法解码某种特殊图片格式，原始文件会自动作为附件插入，不会因为预览失败而丢失。为避免静态网站浏览器本地存储和云端 JSON 快照被大型二进制数据撑满，目前单个图片/附件大小上限为 768 KiB，所有知识库与课时正文中的内嵌媒体总量上限为 1 MiB。附件不会上传到公开文件托管服务，而是内嵌在当前用户的数据中，并随 JSON 备份及已配置的云同步一起保存。普通超链接仅允许 HTTP(S)；内嵌附件采用 MIME 白名单，图片内嵌不接受 SVG。


## 阅读、弹框与撤销机制（2026-11-12 第六轮历史说明；当前行为以第七轮为准）

- **弹框滚动与固定区域（V6 历史实现）**：V6 曾在同一滚动容器内使用 sticky 标题栏和底部操作区；这一实现已在 V7.2 改为真正分离的 CSS Grid 三段式结构，详见第七轮说明。打开弹框时锁定背景页面滚动；点击遮罩外侧不会关闭弹框，必须使用明确的关闭/取消按钮或 Esc。
- **课程阅读位置记忆**：每次课时阅读滚动会按 180ms 防抖写入 `localStorage`，并在页面切换、离开页面和标签页隐藏时补写。记录课时 ID、像素位置、页面滚动比例与视口尺寸；仪表盘“继续学习”会显示“继续上次阅读”，同尺寸设备恢复精确像素位置，不同尺寸设备按比例恢复。阅读位置与课程内容、完成进度和 Supabase 同步数据分离，不会污染课程数据结构。
- **恢复位置竞态修复**：全站有平滑滚动样式，恢复阅读位置时先临时关闭平滑滚动，立即定位，等待两帧渲染稳定后恢复原滚动行为并重新保存，防止恢复过程中的中间位置覆盖已保存锚点。
- **富文本样式持久化**：富文本清洗器在安全白名单内保留 `color`、`background-color`、`font-family`、`font-size` 和段落对齐。文字颜色和背景颜色只接受十六进制、受限 RGB/HSL 或有限命名颜色；没有放开任意 CSS。提交时同步 contenteditable 内容到隐藏字段并进行两次清洗，课时再次打开及阅读渲染时继续保留这些属性。
- **代码块可读性**：旧版 Markdown 课时与富文本课时的 `pre/code` 统一使用深色背景（`#172b21`）和高亮浅色文字（`#edf5ed`），内联代码另用浅底深字，代码块可横向独立滚动，不再出现代码颜色与背景融为一体。
- **课时返回栏**：压缩顶部返回操作区高度，并按桌面 72px / 平板手机 66px 顶栏高度吸顶；返回课程按钮不会随长课时正文滚出视口。
- **多目标删除撤销（V6 历史实现）**：V6 曾按批次合并提示；当前 V7.2 已改为每次删除一张独立提示卡、一个独立 10 秒截止时间和一个独立逆向补丁，点击某张卡片只撤销对应目标。
- **回归脚本**：`node scripts/test-reading-position.mjs` 覆盖相同视口精确恢复、跨视口比例恢复、恢复后写回和滚动行为复原；`node scripts/test-delete-undo.mjs` 覆盖多目标标签、截止时间重置、刷新恢复、模态窗口保护、级联删除与完整快照回滚；`node scripts/test-undo-progress.mjs` 覆盖进度条与倒计时；`node scripts/test-editor-icons.mjs` 覆盖工具图标与分组；`node scripts/validate-project.mjs` 执行当前 23 项静态项目检查。
- **验证边界**：本轮 JavaScript 语法、HTML 入口解析、CSS 递归解析（1583 条规则、5445 项声明，0 项解析错误）和 Node.js 运行时测试均通过。当前执行环境拦截了 Chromium 对本地 HTTP 与 `file://` 页面导航，因此没有声称完成本轮生产浏览器视觉/交互回归；弹框 sticky 与实际部署滚动条仍建议在你的目标浏览器验收。



## 第七轮：弹窗无缝固定区与逐项独立撤销（2026-11-12）

- **弹窗结构改为 CSS Grid 三段式**：每个弹窗都规范为标题区、内容滚动区、底部操作区三个独立直接子节点。标题/关闭按钮位于第一行；只有第二行 `.modal-body` 可以滚动；底部操作区固定在第三行。三个区域使用实色不透明背景，不依赖 `position: sticky`、渐变遮罩、负边距或伪元素遮盖，因此滚动内容不会从标题或按钮后方透出。
- **全面规范化所有弹窗**：`normalizeModalChrome()` 会把普通表单、记录详情、知识卡片、课程/课时/阶段编辑等弹窗统一包装。表单操作组移动到底部后，提交按钮会通过原生 `form` 属性继续关联原始表单，保留 required 校验与 submit 事件。转换函数具备幂等保护，不会重复创建滚动区或底栏。
- **响应式视口适配**：桌面端保留居中弹窗与 22px 外边距；小屏改为 9px 外边距并限制弹窗最大高度；视口高度较小时进一步压缩标题和底部操作区。滚动条仅属于正文区域，轨道和滚动区背景为白色，圆角边界不会裁切冻结按钮。
- **每次删除独立提示**：每一个用户删除动作创建独立 undo ID、逆向补丁、提示卡片、进度条和 10 秒绝对截止时间。连续删除多个对象不会合并提示；新增删除只为新对象启动 10 秒计时，不重置此前其他卡片的剩余时间；撤销其中一个对象只恢复该对象并移除该提示，不影响其他删除项。
- **撤销后重新删除会重新计时**：目标撤销恢复后再次删除，生成全新 ID 和完整 10 秒窗口；与此同时仍待撤销的其他目标继续按自己的截止时间倒计时。刷新标签页后，每个撤销项也会分别从 sessionStorage 恢复原来的截止时间，而不是重新获得 10 秒。
- **集合顺序保持**：针对连续删除同一个数组中的多条记录，补充逻辑顺序与当前物理索引换算。无论先撤销先删除的对象还是后删除的对象，最终都会恢复原始列表顺序；若只撤销其中一条，其他待撤销对象仍保持删除状态。
- **级联删除仍是单个操作**：删除课程或阶段时，一个提示对应用户触发的那一次课程/阶段删除；提示标题明确指出该对象，说明文字补充受影响课时数量及进度/编辑内容，不将级联对象伪装成多条独立用户删除。
- **回归脚本**：`node scripts/test-modal-chrome.mjs` 覆盖表单弹窗、详情弹窗、标题/正文/底栏三个区域、原生表单提交关联及幂等转换；`node scripts/test-delete-undo.mjs` 覆盖不同类型和同类型多目标独立提示、两个撤销顺序、列表顺序恢复、每项独立 10 秒时限、撤销后重删计时、刷新恢复和级联删除；`node scripts/test-undo-progress.mjs` 覆盖每张提示的独立进度条与到期清理；`node scripts/validate-project.mjs` 执行 23 项静态检查。
- **验证边界**：本轮完成 JavaScript 语法检查、Node.js 运行时测试、PostCSS 样式解析和弹窗 DOM 结构单元测试。当前环境未能稳定启动本地 Chromium 页面导航，因此没有将 DOM/CSS 单元测试描述为真实浏览器视觉验收；请在部署环境中再确认目标浏览器的实际滚动表现。
