# Embedded Lab · 嵌入式学习工作台

一个纯 HTML / CSS / JavaScript 的中文嵌入式学习网站，可直接通过 GitHub Pages 发布。无需安装 Node.js、无需构建、无需后端。

## 功能

- **学习总览**：学习时长、课程进度、任务完成和最近记录汇总。
- **学习地图**：现有 14 个知识模块、48 个知识单元。保留原有 C 语言、计算机底层、MCU 启动、GPIO/中断、定时器/PWM、UART/I²C/SPI、ADC/DMA、RTOS、工具链调试和固件可靠性内容，并补齐 GNU Make/Makefile、GCC 与交叉编译、Binutils、链接器与 map 文件、GDB、汇编与 ABI/EABI、MMU/MPU/Cache、Bootloader、硬件信号完整性、软件设计、模块管理、错误管理、单元测试、代码覆盖率、静态/动态分析和性能分析。
- **学习内容详情**：课程卡片可点击进入课程；单元可打开完整正文；支持前后切换、标记完成、课程内导航和把练习带入每日记录。部分单元标注了原书对应章节，方便按书对照学习。
- **学习计划**：预置四周循序渐进的计划，可勾选、添加自定义任务，并指定日期、周次、预计时长和优先级。
- **每日记录**：按日期记录主题、用时、收获/卡点和下一步行动，并可按类别筛选、删除。点击记录卡片或“查看详情”可打开大尺寸详情视图，完整阅读内容；点击“编辑记录”可修改主题、日期、时长、类别、学习收获和下一步行动，保存后会更新原记录而非重复新增。
- **资源收藏**：内置 Arm、CMSIS、STM32、GCC、Git、FreeRTOS、Zephyr 等参考入口；支持自定义链接。
- **我的知识库**：自由增加个人笔记、代码模式、排错记录和项目复盘。
- **偏好与数据**：自定义称呼、每周学习目标；支持导出 JSON、从备份恢复和重置。
- **跨模块搜索**：可搜索课程、课程正文、知识卡片、资源和学习记录。
- **本地持久化**：任务、笔记、记录和进度会保存在当前浏览器的 `localStorage`。

## 本次学习地图扩充说明

本版根据用户提供的李云《专业嵌入式软件开发：全面走向高质高效编程》梳理主题，按原书“硬件、工具、编程语言、设计、操作系统、质量保证”六个方面进行归纳。已有知识点（例如指针与数组、`volatile`、启动流程、链接布局、任务调度与同步）直接补充对应章节提示，不另起重复课程；新增课程则集中填补工程工具链、汇编与 ABI/EABI、硬件信号完整性、模块化设计、错误管理和系统性质量保证方面的内容。

为照顾初学者，课程统一按“核心概念 → 为什么重要 / 常见误区 → 关键要点 → 动手练习”组织，示例以通用 C / MCU 工程场景说明。页面只做知识点归纳和通俗化重写，不复制原书大段文字；详细理论与书中示例应以原著为准。书中部分开发环境和工具版本较早，实际操作时请同时核对目标 MCU、编译器与 RTOS 的当前官方文档。

### 推荐学习顺序

1. **底层基础**：C 语言、内存布局、数值表示、处理器、启动流程、汇编与 ABI。
2. **构建与调试**：Makefile、GCC / 交叉编译、Binutils、链接脚本、map 文件和 GDB。
3. **外设与实时系统**：GPIO、中断、定时器、通信接口、DMA、任务调度、同步原语、内存和设备管理。
4. **工程化与质量**：模块边界、错误管理、可开发性设计、单元测试、覆盖率、静态/动态分析与性能测量。

## 本地预览

建议通过 GitHub Pages 访问，或启动一个本地 HTTP 服务后预览；直接用 `file://` 打开时，部分浏览器会限制 `localStorage`，导致数据无法持久保存。

本地预览示例（需安装 Python）：在该目录执行 `python -m http.server 8000`，然后打开 `http://localhost:8000`。建议使用现代版 Chrome、Edge、Firefox 或 Safari。

## 部署到 GitHub Pages

1. 在 GitHub 创建仓库，例如 `embedded-learning-hub`。
2. 将 `index.html`、`README.md` 上传到仓库根目录并提交。
3. 打开仓库 **Settings → Pages**。
4. 在 **Build and deployment** 中将 Source 设为 **Deploy from a branch**。
5. Branch 选择 `main`，目录选择 `/(root)`，点击 **Save**。
6. 部署完成后使用 GitHub Pages 提供的站点地址访问。

GitHub Pages 可直接发布仓库中的静态文件。GitHub Free 账号的 Pages 通常要求源仓库为公开仓库；发布出的网站可能公开可访问。请勿把个人隐私、账号凭据或敏感数据写入网站代码。

## 数据保存与隐私说明

这是一个静态前端原型，没有用户登录或云端数据库。学习记录、勾选进度、自定义课程和笔记只存放于**当前浏览器的本地存储**，不会自动同步到 GitHub，也不会自动同步到其他设备。清除浏览器站点数据可能导致本地内容丢失，请定期在「偏好与数据」里导出 JSON 备份。导入备份会覆盖当前浏览器中的学习数据。

如果后续要支持账号登录、多设备实时同步或多人共享，需要为它增加后端服务和认证/权限控制（例如 Supabase、Firebase 或自建 API），不应把私人学习记录直接提交到公开 Git 仓库。

## 文件说明

- `index.html`：自包含的网站源码（页面、样式、课程数据和交互逻辑）。
- `README.md`：功能与部署说明。
- `.nojekyll`：避免静态项目被 Jekyll 处理时出现不必要的路径问题。
